Легковесная панель управления и прямой USB-C спулер для 3D-принтера Creality Ender-3 V3 SE. Позволяет управлять устройством и печатать напрямую с компьютера без возни с SD-картой. Интерфейс выполнен в минималистичном стиле Google Gemini с переключением темной и светлой тем на лету и написан на чистом Python (Tkinter) без сторонних GUI-библиотек.

Основные возможности
Прямая печать по USB-C: Построковая потоковая передача G-кода по протоколу Ping-Pong с фильтрацией комментариев и контролем буфера Marlin.

Безопасная пауза: Автоматический откат прутка (3 мм), подъем сопла по Z на 10 мм и отвод в угол стола, исключающий наплывы и прожоги модели.

Экстренный стоп: Мгновенный сброс буфера (M410), полное отключение нагрева сопла (M104 S0), стола (M140 S0), вентилятора и моторов (M84).

Автоподача стола: По окончании печати сопло поднимается на 15 мм и уходит влево (X10), а стол выкатывается вперед (Y210) для легкого снятия детали.

Ручной контроль: Перемещение каретки и стола (шаг 0.1–50 мм), парковка Home, ручной прогрев и пресеты в один клик (PLA 205/60, PETG 230/75, охлаждение).

Понятная телеметрия и ETA: Разбор сырых команд температуры в читаемый вид (текущая и целевая), таймер прошедшего времени и динамический расчет остатка печати.

Кастомный UI: Скругленные кнопки на базе нативного tk.Canvas без тяжелых зависимостей.

Установка и запуск
Требуется Python 3.8+ и стандартный драйвер виртуального COM-порта (CH340/CH341). Соедините принтер с ПК кабелем USB-C с поддержкой передачи данных.

Bash
git clone https://github.com/your-username/ender3-v3se-studio-control.git
cd ender3-v3se-studio-control
pip install pyserial
python printer_gui.py
Сборка в автономный .exe
Для упаковки приложения в один файл с иконкой:

Bash
pip install pyinstaller
pyinstaller --noconsole --onefile --clean --icon="app_icon.ico" printer_gui.py
Исполняемый файл появится в папке dist/.
